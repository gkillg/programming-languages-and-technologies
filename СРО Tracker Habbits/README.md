# 👾 Habby: Retro GameBoy Habit Tracker

> **Учебный проект (СРО)** по дисциплине «Языки и технология программирования»  
> **Группа:** ИС-25-22

---

### 📖 О проекте

**Habby** — интерактивный веб-трекер полезных привычек, оформленный в виде ретро-консоли **Game Boy Color**.

Каждая привычка представлена в виде **RPG-квеста**: выполняя цели на день, игрок зарабатывает очки опыта (**XP**), повышает уровень героя и прокачивает серии побед (Combo).

---

### 🕹️ Ключевой функционал

- 🎮 **Интерфейс Game Boy**: Ретро-корпус, CRT-эффект экрана, D-Pad и пиксельный стиль.
- 🐾 **Питомец Habby**: Анимированный пиксельный маскот с фразами поддержки.
- ⚔️ **Геймификация**: Начисление XP, система уровней (Level Up) и множитель серий.
- 💾 **Экспорт карточки**: Генерация пиксельной PNG-картинки с итогами дня для соцсетей.
- 📋 **Шеринг**: Быстрое копирование прогресса с эмодзи в буфер обмена.
- 📁 **Персистентность**: Хранение в JSON с защитой от сбоев.

---

### 🚀 Запуск программы

1. Установите зависимости:
```bash
pip install flask
```

2. Запустите веб-сервер:
```bash
python app.py
```

3. Откройте в браузере: `http://localhost:5000`

### 🧪 Тест-кейсы для сдачи СРО

| ID | Тип теста | Сценарий проверки | Входные данные | Ожидаемый результат |
| :--- | :--- | :--- | :--- | :--- |
| **TC-01** | Основной | Добавление нового квеста | Текст: `Читать 20 мин` → `+ КВЕСТ` | Квест добавлен, начислено **+15 XP**, проигран 8-битный звук. |
| **TC-02** | Основной | Закрытие квеста за сегодня | Клик `ВЫПОЛНИТЬ` | Статус меняется на `✔ ЗАКРЫТ`, комбо **x1**, шкала дня растет. |
| **TC-03** | Основной | Генерация графической карточки | Клик `💾 СКАЧАТЬ КАРТОЧКУ` | Браузер скачивает сгенерированный файл **`habby-card.png`**. |
| **TC-04** | Основной | Копирование текста успехов | Клик `📋 СКОПИРОВАТЬ ТЕКСТ` | Текст со статистикой и эмодзи скопирован в буфер обмена. |
| **TC-05** | Ошибка ввода | Попытка добавить пустой квест | Клик `+ КВЕСТ` с пустым полем | Форма блокируется валидатором: `Имя квеста не может быть пустым`. |
| **TC-06** | Ошибка ввода | Создание дубликата задачи | Ввод уже существующего имени | Уведомление: `Такой квест уже записан!`, дубликат не создается. |
| **TC-07** | Граничный | Сброс комбо (серии) | Клик по кнопке `0` | Серия сбрасывается в **0**, рекорд квеста сохраняется. |
| **TC-08** | Граничный | Фильтрация по статусу | Вкладка `ГОТОВО` | Отображаются только привычки, выполненные сегодня. |
