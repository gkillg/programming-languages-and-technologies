Лабораторная работа №12: Аутентификация и работа с токенами (JWT)Дисциплина: Языки и технология программированияВариант: №15 — JWT-демо: сервер выдает короткоживущий JWT, защищенный endpoint проверяет подпись и срок действия.📋 Описание проектаУчебный веб-прототип клиент-серверного приложения на JavaScript (Node.js + Express + Vanilla JS), демонстрирующий полный жизненный цикл JSON Web Token (JWT):Аутентификация пользователя (POST /api/login) с проверкой учетных данных на сервере.Генерация короткоживущего JWT (алгоритм HS256, время жизни 5 минут).Интерактивный разбор токена на клиенте (визуализация Header и Payload).Авторизация и защита ресурсов (GET /api/protected) с проверкой подписи, алгоритма и срока действия токена (exp) на стороне сервера.Завершение сессии (Logout) с очисткой клиентского хранилища.🏗 Архитектура приложения[Браузер (Клиент)]                         [Сервер (Node.js / Express)]
       │                                                 │
       ├── 1. POST /api/login (учетные данные) ─────────►│ Проверка логина/пароля
       │◄── 2. HTTP 200 OK + JWT (exp: +5m) ─────────────┤ Генерация подписи HS256
       │                                                 │
       ├── 3. GET /api/protected ───────────────────────►│ Middleware verifyJWT:
       │      Header: Authorization: Bearer <token>      │ - Проверка подписи
       │◄── 4. HTTP 200 OK (данные) / 401 / 403 ─────────┤ - Проверка срока (exp)
       │                                                 │
       └── 5. Выход (удаление токена на клиенте)         │

🚀 Установка и запускТребованияУстановленный Node.js (версии 16 и выше) и менеджер пакетов npm.Шаги запускаКлонируйте репозиторий и перейдите в директорию проекта:git clone <url-вашего-репозитория>
cd lab12-jwt
Установите необходимые зависимости:npm install express jsonwebtoken
Запустите сервер:node server.js
Откройте браузер и перейдите по адресу:http://localhost:3000
