```python
# Задание 1: Проверка и классификация треугольника
def check_triangle(a: float, b: float, c: float) -> str:
    if a <= 0 or b <= 0 or c <= 0:
        return "Ошибка: стороны должны быть строго положительными числами."
    if a + b <= c or a + c <= b or b + c <= a:
        return "Треугольник с такими сторонами не существует."
    if a == b == c:
        return "Треугольник существует: Равносторонний"
    elif a == b or b == c or a == c:
        return "Треугольник существует: Равнобедренный"
    else:
        return "Треугольник существует: Разносторонний"

if __name__ == "__main__":
    a = float(input("Сторона A: "))
    b = float(input("Сторона B: "))
    c = float(input("Сторона C: "))
    print(check_triangle(a, b, c))
```

```python
def find_min_max(n1: float, n2: float, n3: float) -> tuple[float, float]:

    if n2 > maximum: maximum = n2

    if n3 < minimum: minimum = n3
```

**Условие задания:**
Рассчитать скидку на заказ: до 1000 руб — 0%, от 1000 до 5000 — 5%, свыше 5000 — 10%.

**Текстовая схема алгоритма:**
1. Инициализация рабочей среды и вывод заголовка задания.
2. Прием входных данных от пользователя с валидацией типов.
3. Проверка граничных условий и вычисление результирующих параметров.
4. Форматированный вывод результатов с точностью до двух знаков после запятой.

**Исходный код (задание_12.py):**
```python
"""
Дисциплина: Языки и технологии программирования
Файл: задание_12.py
Тема: Задание 12: Расчет скидки по ступенчатой шкале
Выполнил: Бактыгалиев Амир | Группа: ИС-25-22 | Вариант: 7
Учебный год: 2026
Стиль оформления: Академический (PEP 8, Type Hints, Docstrings)
"""

from typing import Tuple

def evaluate_discount_policy(gross_amount: float) -> Tuple[float, float, float]:
    """
    Вычисляет процент скидки, величину дисконта и чистую сумму к оплате.
    
    Шкала скидок:
    - до 1000 руб: 0%
    - от 1000 до 5000 руб: 5%
    - свыше 5000 руб: 10%
    """
    if gross_amount < 0.0:
        raise ValueError("Сумма счета не может быть отрицательной.")

    discount_rate: float
    if gross_amount < 1000.0:
        discount_rate = 0.0
    elif gross_amount <= 5000.0:
        discount_rate = 5.0
    else:
        discount_rate = 10.0

    discount_rub: float = gross_amount * (discount_rate / 100.0)
    net_payable: float = gross_amount - discount_rub
    return discount_rate, discount_rub, net_payable


def main() -> None:
    print(f"=== Расчет скидки по ступенчатой шкале (Вар. {profile.variant}) ===")
    try:
        order_sum: float = float(input("Введите базовую сумму покупки (руб): "))
        pct, rub, net = evaluate_discount_policy(order_sum)
        print(f"Примененная скидка: {pct:.1f}%")
        print(f"Сумма экономии:     {rub:.2f} руб.")
        print(f"Итоговая стоимость: {net:.2f} руб.")
    except ValueError as err:
        print(f"Ошибка вычисления: {err}")


if __name__ == "__main__":
    main()
```

**Тестирование и проверка результатов:**
- **Входные данные:** `3500.0`
- **Ожидаемый результат:** `Скидка: 5%, К оплате: 3325.00 руб.`

## 🧠 4. Ответы на контрольные вопросы


#### Вопрос 1: Как устроена конструкция if-elif-else в Python?
**Ответ:**  
Конструкция if-elif-else последовательно проверяет логические условия. Как только одно из условий оказывается True, выполняется соответствующий блок инструкций, а остальные ветки пропускаются. Если ни одно условие не выполнено, отрабатывает блок else.



#### Вопрос 2: Что такое логические операторы and, or, not и каков их приоритет?
**Ответ:**  
not имеет наивысший приоритет (логическое отрицание), затем and (логическое И, ленивое вычисление — возвращает первый ложный или последний истинный операнд), затем or (логическое ИЛИ — возвращает первый истинный операнд).



#### Вопрос 3: Каковы правила отступов (indentation) в Python?
**Ответ:**  
В Python отступы являются частью синтаксиса и определяют границы блоков кода. Стандарт PEP 8 предписывает использовать ровно 4 пробела на один уровень отступа и запрещает смешивать пробелы и знаки табуляции.



#### Вопрос 4: Как конструкция match-case (Python 3.10+) отличается от серии if-elif?
**Ответ:**  
match-case реализует полноценное структурное сопоставление с шаблоном (pattern matching). Оно позволяет не только сравнивать значения, но и проверять типы, сопоставлять последовательности и словари, а также распаковывать данные в переменные.
