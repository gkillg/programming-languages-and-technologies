## 🔍 Лабораторная работа №12: JWT-демо (Вариант 15)

Реализация безопасного клиент-серверного взаимодействия с использованием JSON Web Token.

### Архитектура и функционал:
1. **Серверная часть (`server.js`):**
   * Обработка запроса авторизации (`POST /api/login`) с проверкой учетных данных.
   * Генерация короткоживущего JWT (алгоритм `HS256`, срок действия `5 минут`).
   * Защищенный маршрут (`GET /api/protected`) с middleware верификации подписи и срока действия токена (`exp`).
   * Возврат корректных HTTP-статусов (`200 OK`, `401 Unauthorized`, `403 Forbidden`).

2. **Клиентская часть (`public/index.html`):**
   * Форма авторизации и управления сессией.
   * **Интерактивный анализатор JWT в реальном времени:** автоматический разбор токена на клиенте с визуализацией `Header` и `Payload`.

### 🚀 Быстрый запуск Lab 12:

1. Установите зависимости:
   ```bash
   npm install express jsonwebtoken
   ```
2. Запустите сервер:
   ```bash
   node server.js
   ```
3. Откройте в браузере: **`http://localhost:3000`**
