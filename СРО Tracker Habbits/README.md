# 👾 Habby: Web Pixel Habit Tracker

Учебный проект по дисциплине «Языки и технология программирования».

**Habby** — полнофункциональный веб-трекер полезных привычек в ретро-эстетике классического Game Boy с интерактивным помощником, системой начисления XP, повышением уровней и отслеживанием комбо-серий.

Запустите веб-сервер:

python app.py
После запуска откройте ссылку в браузере (в Codespaces появится всплывающее окно "Open in Browser", либо перейдите по адресу http://localhost:5000).


🧪 Тест-кейсы для сдачи работы
ID	Тип теста	Сценарий	Входные данные	Ожидаемый результат
TC-01	Основной	Добавление новой привычки	Ввод Пробежка 15 мин -> Нажать + СОЗДАТЬ	Привычка появляется в списке, игроку начисляется +10 XP.
TC-02	Основной	Отметка квеста	Клик по кнопке ВЫПОЛНИТЬ	Статус меняется на ✔ СДЕЛАНО, серия x1, полоса дня заполняется.
TC-03	Основной	Повышение уровня (Level Up)	Закрытие квестов до достижения лимита шкалы EXP	Уровень увеличивается (Lv.2), шкала сбрасывается.
TC-04	Основной	Удаление привычки	Клик по кнопке ✖ напротив привычки	Привычка безвозвратно удаляется из интерфейса и JSON.
TC-05	Ошибка ввода	Попытка добавить пустую строку	Клик + СОЗДАТЬ с пустым полем	Форма блокируется валидатором, выводится ошибка Имя не может быть пустым.
TC-06	Ошибка ввода	Создание дубликата задачи	Ввод уже существующего названия	Уведомление Такой квест уже есть в свитке!, дубликат не создается.
TC-07	Граничный	Сброс комбо (серии)	Клик по кнопке 🔄	Серия сбрасывается до x0, лучший рекорд сохраняется.
TC-08	Граничный	Защита от повторного выполнения	Попытка повторно выполнить закрытую задачу	Кнопка становится неактивной со статусом ✔ СДЕЛАНО.
