## 🧠 4. Ответы на контрольные вопросы


#### Вопрос 1: Что такое JSON и чем он отличается от объекта JavaScript?
**Ответ:**  
JSON (JavaScript Object Notation) — это текстовый независимый формат обмена данными со строгим синтаксисом (двойные кавычки для строк и ключей, отсутствие функций, методов, undefined и циклических ссылок). Объект JavaScript — это динамическая структура в оперативной памяти с прототипом, методами и ссылочной моделью.



#### Вопрос 2: Для чего нужны JSON.stringify() и JSON.parse()?
**Ответ:**  
JSON.stringify() сериализует объект или массив JavaScript в строку формата JSON для передачи по сети или сохранения в Web Storage. JSON.parse() десериализует JSON-строку обратно в структуру данных JavaScript (объект, массив, примитив).



#### Вопрос 3: Почему localStorage хранит исключительно строки?
**Ответ:**  
Спецификация W3C Web Storage определяет интерфейс хранения ключ-значение строго как тип DOMString (UTF-16 строки). При попытке записать объект напрямую без stringify браузер вызовет метод .toString() и сохранит бесполезную строку '[object Object]'.



#### Вопрос 4: Чем localStorage отличается от sessionStorage?
**Ответ:**  
localStorage сохраняет данные бессрочно в рамках одного источника (origin: протокол + домен + порт) даже после закрытия вкладки и перезапуска браузера. sessionStorage живет только в контексте текущей вкладки и автоматически уничтожается при ее закрытии.



#### Вопрос 5: Что возвращает getItem() для отсутствующего ключа и как безопасно распарсить данные?
**Ответ:**  
Метод getItem() возвращает null. Для безопасного парсинга применяется конструкция: JSON.parse(localStorage.getItem(key) || '[]') внутри блока try...catch, предотвращающего падение приложения при поврежденном или невалидном JSON.



#### Вопрос 6: Как удалить запись по ключу и как полностью очистить хранилище текущего источника?
**Ответ:**  
Для удаления конкретного элемента используется localStorage.removeItem('key'). Для полной очистки всех записей текущего домена/источника используется метод localStorage.clear().



#### Вопрос 7: Почему нельзя хранить пароли, реальные токены и персональные секреты в Web Storage?
**Ответ:**  
Хранилища localStorage и sessionStorage полностью доступны любому JavaScript-коду, исполняющемуся на странице. В случае XSS-уязвимости (Cross-Site Scripting) злоумышленник может беспрепятственно прочитать все токены и секреты.
