### 📖 О проекте

**Habby** — это интерактивный многопользовательский веб-трекер привычек, оформленный в виде ретро-консоли **Game Boy Color**. 

Каждый пользователь получает собственный **слот сохранения с уникальным ретро-ID** (`HB-XXXX`), заводит питомца Habby и прокачивает свой уровень (XP), превращая рутинные задачи в RPG-квесты.

---

### 🕹️ Ключевой функционал

- 👥 **Мультипользовательский режим (Multi-User)**:
  - Генерация персонального ID игрока (например, `HB-7412`).
  - Возможность войти по своему ID с любого устройства и продолжить прогресс.
  - Полная изоляция данных: у каждого пользователя свои квесты, уровень и статистика.
- 🎮 **Ретро-интерфейс Game Boy**: Корпус консоли, CRT-сканлайны, пиксельный шрифт, 8-битные звуки Web Audio API.
- 🐾 **Компаньон Habby**: Живой пиксельный маскот с анимацией и контекстными репликами.
- ⚔️ **Геймификация**: Начисление XP, динамический Level Up, комбо-серии (Streak).
- 💾 **Экспорт карточки**: Генерация пиксельного сертификата достижений (`.png`) через HTML5 Canvas.
- 📋 **Шеринг**: Быстрое копирование прогресса с эмодзи в буфер обмена.
- 📁 **Персистентность**: Надежное сохранение структуры данных пользователей в `habby_save.json`.

### 🚀 Запуск программы

1. Установите зависимости:
```bash
pip install flask
```

2. Запустите веб-сервер:
```bash
python app.py
```

3. Откройте в браузере: **`http://localhost:5000`**

### 🧪 Тест-кейсы 

| ID | Тип теста | Сценарий проверки | Входные данные | Ожидаемый результат |
| :--- | :--- | :--- | :--- | :--- |
| **TC-01** | Основной | Создание нового героя | Имя: `Amir` → `СТАРТ` | Создан слот, выдан уникальный ID (напр. `HB-1024`), открыт чистый журнал. |
| **TC-02** | Основной | Загрузка по существующему ID | Ввод ID `HB-1024` → `ВОЙТИ` | Успешный вход в существующий профиль, подгружены все привычки и уровень. |
| **TC-03** | Основной | Добавление и закрытие квеста | `Бег 20 мин` → `ВЫПОЛНИТЬ` | Задача помечается `✔ ЗАКРЫТ`, комбо x1, начислен опыт (+30 XP). |
| **TC-04** | Основной | Генерация графической карточки | Клик `💾 СКАЧАТЬ КАРТОЧКУ` | Canvas генерирует и скачивает `habby-HB-1024.png` с ником и статистикой. |
| **TC-05** | Ошибка ввода | Вход по несуществующему ID | Ввод `HB-9999` (нет в базе) | Ошибка `Герой с таким ID не найден на картридже!`, вход заблокирован. |
| **TC-06** | Ошибка ввода | Создание дубликата квеста | Повторный ввод существующего имени | Уведомление: `Такой квест уже записан в свитке!`, дубликат не создается. |
| **TC-07** | Граничный | Изоляция данных пользователей | Вход под ID_1, затем под ID_2 | Пользователь 2 не видит привычки Пользователя 1. Списки полностью независимы. |
| **TC-08** | Граничный | Защита от накрутки опыта | Повторный клик по закрытому квесту | Кнопка неактивна, статус `✔ ЗАКРЫТ`, опыт не начисляется дважды. |
