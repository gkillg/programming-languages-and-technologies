# 👾 Habby: Retro GameBoy Habit Tracker

> **Учебный проект (СРО)** по дисциплине «Языки и технология программирования»  
> **Группа:** ИС-25-22

---

### 📖 О проекте

**Habby** — это интерактивный веб-трекер полезных привычек, стилизованный под культовую ретро-консоль **Game Boy Color**.

Каждая привычка здесь представлена в виде **RPG-квеста**: выполняя цели на день, игрок зарабатывает очки опыта (**XP**), повышает уровень персонажа и радует виртуального 8-битного питомца **Habby**.

---

### 🕹️ Ключевой функционал

- 🎮 **Интерфейс Game Boy**: Корпус консоли, экран с CRT-сканлайнами, D-Pad и пиксельный шрифт.
- 🐾 **Питомец Habby**: Интерактивный спутник с анимациями и фразами поддержки.
- ⚔️ **Геймификация**: Начисление XP, система уровней (Level Up) и множитель серий (Combo/Streak).
- 💾 **Генерация карточки (Canvas)**: Возможность скачать готовую PNG-картинку своих успехов для соцсетей.
- 📋 **Шеринг**: Быстрое копирование прогресса в буфер обмена в виде аккуратного эмодзи-отчета.
- 📁 **Персистентность**: Надежное сохранение данных в JSON с защитой от сбоев.
