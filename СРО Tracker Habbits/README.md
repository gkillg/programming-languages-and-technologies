## 1. Описание проекта и актуальность

**Habby** — это интерактивный многопользовательский веб-трекер полезных привычек, стилизованный под культовую ретро-консоль **Game Boy Color**.

### Проблема
Классические трекеры привычек страдают от синдрома «усталости от чеклистов» (*Checklist Fatigue*). Монотонные таблицы и списки с галочками быстро превращаются в унылую бюрократию, из-за чего пользователи бросают фиксацию целей уже на 5–7 день.

### Цель и решение
Повысить регулярность выполнения привычек за счет **эмоциональной геймификации**:
- Рутинные задачи превращаются в **RPG-квесты**.
- За выполнение начисляются очки опыта (**XP**) и повышается уровень героя (**Level Up**).
- Интерактивный 8-битный питомец **Habby** радуется победам и мотивирует при простоях.
- Фиксация комбо-серий (**Streak**) с защитой персональных рекордов.

**Целевая аудитория:** Студенты, разработчики и все, кто хочет привить себе микро-привычки (учеба, чтение, спорт) через игровую мотивацию.

## 3. Формализация требований

### Функциональные требования (FR):
- **FR-1:** Многопользовательский режим с генерацией уникального ID (`HB-XXXX`) и авторизацией.
- **FR-2:** Полный CRUD-цикл управления квестами (создание, просмотр, сброс серии, удаление).
- **FR-3:** Автоматический пересчет комбо (серий) на основе библиотеки `datetime` с фиксацией личного рекорда.
- **FR-4:** Ролевая система: начисление опыта (XP) и динамический расчет уровня игрока (Level Up).
- **FR-5:** Интерактивный виртуальный помощник Habby, меняющий реплики от статуса выполнения плана.
- **FR-6:** Социальный шеринг: рендеринг персональной PNG-карточки через HTML5 Canvas и копирование сводки с эмодзи.

### Нефункциональные требования (NFR):
- **NFR-1 (Надежность):** Безопасный парсинг данных с fallback-инициализацией базы при повреждении файла (`try-except`).
- **NFR-2 (Производительность):** Время отклика страниц < 50 мс; синтез звуков без загрузки внешних аудиофайлов.
- **NFR-3 (Юзабилити):** Полная стилизация под Game Boy Color, контрастный 8-bit интерфейс, CRT-сканлайны экрана.

### Пользовательские сценарии (Use Cases):
1. **Создание слота:** Пользователь вводит ник $\rightarrow$ система присваивает ID `HB-1024` $\rightarrow$ открывается чистый журнал квестов.
2. **Закрытие привычки:** Пользователь жмет «ВЫПОЛНИТЬ» $\rightarrow$ статус меняется на «✔ ЗАКРЫТ» $\rightarrow$ начисляется +30 XP $\rightarrow$ растет шкала дня $\rightarrow$ Habby выдает восторженную реплику.
3. **Сохранение карточки:** Пользователь кликает «СКАЧАТЬ КАРТОЧКУ» $\rightarrow$ в память устройства сохраняется картинка `habby-HB-1024.png` с текущим уровнем и прогрессом.

## 5. Инструкция по установке и запуску

**Требования к окружению:** Python версии 3.8 или выше.

```bash
# 1. Перейти в каталог проекта
cd "СРО Tracker Habbits"

# 2. Установить микрофреймворк Flask
pip install flask

# 3. Запустить веб-приложение
python app.py
```
После запуска откройте в браузере: **`http://localhost:5000`** *(или нажмите "Open in Browser" в Codespaces)*.

### Обнаруженные и устраненные дефекты:
1. **Дефект:** При пропуске дня комбо не сгорало, если приложение было выключено.  
   *Исправление:* Реализована функция `update_streaks_on_load()`, которая сравнивает сохраненную дату с `date.today()` при каждом входе.
2. **Дефект:** Валидатор HTML в VS Code ругался на синтаксис Jinja2 внутри `style="..."`.  
   *Исправление:* Расчет ширины шкал перенесен в JS через data-атрибуты (`data-percent`).
