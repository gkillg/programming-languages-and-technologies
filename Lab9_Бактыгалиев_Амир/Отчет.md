## 🧠 4. Ответы на контрольные вопросы


#### Вопрос 1: Что такое AJAX и концепция REST API?
**Ответ:**  
AJAX (Asynchronous JavaScript and XML) — концепция фонового обмена данными между браузером и сервером без перезагрузки веб-страницы. REST API (Representational State Transfer) — архитектурный стиль взаимодействия систем по протоколу HTTP с использованием стандартных методов (GET, POST, PUT, DELETE) и формата JSON.



#### Вопрос 2: Чем асинхронный запрос отличается от синхронного?
**Ответ:**  
Синхронный запрос полностью блокирует поток выполнения JavaScript (Event Loop) и замораживает пользовательский интерфейс браузера до получения ответа от сети. Асинхронный запрос выполняется в фоновом режиме, возвращая Promise, и позволяет интерфейсу оставаться интерактивным.



#### Вопрос 3: Что возвращает функция fetch() и почему необходимо проверять response.ok?
**Ответ:**  
fetch() возвращает Promise, который переходит в состояние fulfilled при получении любого HTTP-ответа от сервера. Даже если сервер вернул ошибку 404 (Not Found) или 500 (Internal Server Error), fetch() НЕ переходит в блок catch. Поэтому проверка свойства response.ok (код ответа в диапазоне 200–299) строго обязательна.



#### Вопрос 4: Для чего используются ключевые слова async и await?
**Ответ:**  
async объявляет функцию, которая неявно возвращает Promise. await приостанавливает выполнение асинхронной функции до тех пор, пока переданный Promise не разрешится значением или ошибкой, позволяя писать асинхронный код в линейном, синхронном виде без громоздких цепочек .then() и callback-ов.



#### Вопрос 5: Что такое CORS и почему возникают CORS-ошибки?
**Ответ:**  
CORS (Cross-Origin Resource Sharing) — механизм безопасности браузера, блокирующий запросы со страницы на сторонний домен/порт, если целевой сервер явно не разрешил этот запрос в HTTP-заголовке Access-Control-Allow-Origin.



#### Вопрос 6: Почему нельзя доверять содержимому ответа стороннего сервера?
**Ответ:**  
Данные от сервера могут содержать вредоносный HTML/JS-код (Stored XSS). Для предотвращения XSS-атак данные выводятся в DOM исключительно через textContent или создание DOM-элементов, избегая конкатенации в innerHTML.



#### Вопрос 7: Для чего используется AbortController?
**Ответ:**  
AbortController предоставляет объект сигнала (signal), который передается в параметры fetch(). Метод controller.abort() позволяет отменить ранее отправленный сетевой запрос (например, при быстром наборе текста в строке поиска с debounce).
