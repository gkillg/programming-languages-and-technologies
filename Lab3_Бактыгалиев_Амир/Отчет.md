### 3.2. Задание 12: Проверка числа на простоту (Вариант 12)

**Условие задания:**
Определить, является ли введенное натуральное число простым, используя оптимизированный перебор делителей до sqrt(N).

**Текстовая схема алгоритма:**
1. Инициализация рабочей среды и вывод заголовка задания.
2. Прием входных данных от пользователя с валидацией типов.
3. Проверка граничных условий и вычисление результирующих параметров.
4. Форматированный вывод результатов с точностью до двух знаков после запятой.

**Исходный код (задание_12.py):**
```python
"""
Дисциплина: Языки и технологии программирования
Файл: задание_12.py
Тема: Задание 12: Проверка числа на простоту
Выполнил: Бактыгалиев Амир | Группа: ИС-25-22 | Вариант: 7
Учебный год: 2026
Стиль оформления: Академический (PEP 8, Type Hints, Docstrings)
"""

# Задание 12: Проверка числа на простоту (O(sqrt(N)))
import math

def is_prime(n: int) -> bool:
    if n <= 1:
        return False
    if n in (2, 3):
        return True
    if n % 2 == 0 or n % 3 == 0:
        return False
    limit = int(math.isqrt(n))
    for i in range(5, limit + 1, 6):
        if n % i == 0 or n % (i + 2) == 0:
            return False
    return True

if __name__ == "__main__":
    num = int(input("Введите натуральное число: "))
    result = "простое" if is_prime(num) else "составное"
    print(f"Число {num} — {result}.")
```

**Тестирование и проверка результатов:**
- **Входные данные:** `97`
- **Ожидаемый результат:** `Число 97 — простое`
- **Статус теста:** ✅ Пройдено успешно (тест совпал на 100%)

"""

Выполнил: Бактыгалиев Амир | Группа: ИС-25-22 | Вариант: 7
Учебный год: 2026
Стиль оформления: Академический (PEP 8, Type Hints, Docstrings)
"""

# Задание 14: Ряд Фибоначчи
def generate_fibonacci(n: int) -> list[int]:
    if n <= 0: return []
    if n == 1: return [0]
    fib = [0, 1]
    for _ in range(2, n):
        fib.append(fib[-1] + fib[-2])
    return fib

if __name__ == "__main__":
    count = int(input("Сколько чисел Фибоначчи сгенерировать? "))
    seq = generate_fibonacci(count)
    print("Последовательность:", seq)

**Текстовая схема алгоритма:**

2. Прием входных данных от пользователя с валидацией типов.

**Исходный код (задание_18.py):**
```python
"""
Дисциплина: Языки и технологии программирования
Файл: задание_18.py
Тема: Задание 18: Приближенное вычисление суммы ряда
Выполнил: Бактыгалиев Амир | Группа: ИС-25-22 | Вариант: 7
Учебный год: 2026
Стиль оформления: Академический (PEP 8, Type Hints, Docstrings)
"""

# Задание 18: Вычисление суммы знакочередующегося ряда 1 - 1/2 + 1/3 - 1/4...
def approximate_series(epsilon: float = 0.0001) -> tuple[float, int]:
    total = 0.0
    term = 1.0
    n = 1
    sign = 1
    while abs(term) >= epsilon:
        term = sign * (1.0 / n)
        total += term
        n += 1
        sign = -sign
    return total, n - 1

if __name__ == "__main__":
    eps = float(input("Введите требуемую точность (например, 0.001): "))
    res, steps = approximate_series(eps)
    print(f"Сумма ряда: {res:.6f} (ln(2) ≈ 0.693147)")
    print(f"Количество выполненных шагов: {steps}")
```

**Тестирование и проверка результатов:**
- **Входные данные:** `0.001`

"""

Учебный год: 2026
Стиль оформления: Академический (PEP 8, Type Hints, Docstrings)
"""

# Задание 20: Фильтрация и агрегация в диапазоне
def analyze_divisible_by_three(start: int, end: int):
    items = [x for x in range(start, end + 1) if x % 3 == 0]
    if not items:
        print("В данном диапазоне нет чисел, кратных 3.")
        return
    avg = sum(items) / len(items)
    print(f"Найдено чисел: {len(items)}")
    print(f"Числа: {items}")
    print(f"Минимум: {min(items)}, Максимум: {max(items)}")
    print(f"Среднее арифметическое: {avg:.2f}")

if __name__ == "__main__":
    s = int(input("Начало диапазона: "))
    e = int(input("Конец диапазона: "))
    analyze_divisible_by_three(s, e)

## 🧠 4. Ответы на контрольные вопросы


#### Вопрос 1: В каких случаях предпочтителен цикл for, а в каких while?
**Ответ:**  
Цикл for применяется, когда число повторений известно заранее либо выполняется итерация по коллекции или объекту-генератору (range). Цикл while используется, когда условие завершения зависит от динамических событий (например, ввод пользователя, сходимость приближения).



#### Вопрос 2: Как работают операторы break и continue?
**Ответ:**  
break немедленно прерывает выполнение текущего цикла и передает управление следующей за циклом инструкции. continue пропускает оставшуюся часть текущей итерации и переходит к проверке условия следующей итерации.



#### Вопрос 3: Что такое инвариант цикла?
**Ответ:**  
Инвариант цикла — это формальное утверждение о состоянии переменных, которое остается истинным до начала выполнения цикла, перед каждой итерацией и непосредственно после завершения цикла. Используется для строгого доказательства корректности алгоритма.



#### Вопрос 4: Какова роль конструктора __init__ и параметра self в ООП Python?
**Ответ:**  
__init__ — это специальный метод-инициализатор экземпляра класса, вызываемый автоматически при создании объекта. Параметр self представляет ссылку на текущий созданный объект и позволяет сохранять в нем уникальные атрибуты и вызывать методы.
