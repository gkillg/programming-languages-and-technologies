### 1. Описание проекта и актуальность
* **Цель проекта:** Разработка веб-приложения для выработки и поддержания регулярных полезных привычек с применением ретро-геймификации (стилистика Game Boy / 8-bit RPG).
* **Проблема:** Классические трекеры страдают от проблемы «синдрома выгорания чеклистов» (Checklist Fatigue). Пользователи забрасывают фиксацию рутины уже через 5–7 дней из-за отсутствия эмоционального отклика и монотонного интерфейса.
* **Целевая аудитория:** Студенты, разработчики, молодые специалисты, любители ретро-эстетики и видеоигр, желающие внедрить микро-привычки (спорт, учеба, чтение, режим) в игровом формате.

### 3. Формализация требований

#### Функциональные требования (FR):
* **FR-1:** Многопользовательский режим с генерацией уникального ID (`HB-XXXX`) и авторизацией.
* **FR-2:** Полный CRUD привычек (создание, просмотр, сброс серии, удаление).
* **FR-3:** Автоматический пересчет комбо (серий) на основе `datetime` и фиксация рекордов.
* **FR-4:** Ролевая система: начисление XP за действия, шкала прогресса, автоматический Level Up.
* **FR-5:** Интерактивный виртуальный помощник Habby, динамически меняющий реплики.
* **FR-6:** Социальный шеринг: экспорт персональной карточки в PNG через Canvas и копирование сводки.

#### Нефункциональные требования (NFR):
* **NFR-1 (Надежность):** Безопасный парсинг JSON с fallback-схемой при сбоях (`try-except`).
* **NFR-2 (Производительность):** Время отклика сервера < 50 мс; синтез звуков без загрузки тяжелых MP3.
* **NFR-3 (Юзабилити):** Полная адаптация под стилистику Game Boy Color, контрастный 8-bit UI, сканлайны.

#### Пользовательские сценарии (Use Cases):
1. **Регистрация и старт:** Пользователь вводит ник -> получает слот с ID `HB-1024` -> попадает в журнал квестов.
2. **Ежедневный цикл:** Пользователь нажимает «ВЫПОЛНИТЬ» -> статус меняется на «✔ ЗАКРЫТ» -> начисляется опыт (+30 XP) -> растет комбо -> Habby выдает подбадривающую реплику.
3. **Шеринг:** Пользователь кликает «СКАЧАТЬ КАРТОЧКУ» -> браузер сохраняет PNG с его текущим уровнем и прогрессом за день.
