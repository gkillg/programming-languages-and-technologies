# 👾 Habby: Retro GameBoy Habit Tracker

Учебный проект (СРО) по дисциплине «Языки и технология программирования».

**Habby** — интерактивный ретро-трекер полезных привычек, оформленный в виде портативной консоли Game Boy. Каждая привычка — квест, за который дается опыт (XP), прокачивается уровень героя, а пиксельный компаньон Habby мотивирует не пропускать дни.

---

## 🎮 Новые возможности
1. **Корпус ретро-консоли:** Стилизованный Game Boy с CRT-сканлайнами, джойстиком и звуками Web Audio.
2. **Экспорт и шаринг (Social Sharing):** 
   - Генерация пиксельной PNG-карточки достижений прямо в браузере (через HTML5 Canvas).
   - Быстрое копирование эмодзи-сводки для соцсетей.
3. **Фильтрация задач:** Быстрое переключение между активными и закрытыми квестами.
4. **Сохранение в JSON:** Персистентное хранилище с обработкой ошибок повреждения файлов.
